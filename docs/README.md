# OctoAcme Project Management Docs

This README centralizes OctoAcme's project management process documents and provides quick links and a short summary of each process area.

## Brief summary of OctoAcme project management processes

- Project management overview — high-level principles, goals, and how processes fit together.
- Project initiation — criteria, intake, and approval steps for new projects.
- Project planning — scope, milestones, estimation, and planning artifacts.
- Execution & tracking — how work is executed, sprint/iteration cadence, status reporting, and metrics.
- Risks & communication — risk identification, escalation paths, and stakeholder communication guidelines.
- Release & deployment — release checklists, deployment procedures, and rollback plans.
- Retrospective & continuous improvement — cadence for retros, feedback loops, and process updates.
- Roles & personas — responsibilities and contact points for the core roles involved.

## How to contribute

1. Add or update files under docs/ with process content.
2. Open a pull request describing the change and link to the relevant issue (if any).
3. Request review from stakeholders responsible for the process area.

---

### Acceptance Criteria

- Content aligns with existing process docs
- Update improves clarity or closes a documented gap
- Proposed content has been reviewed with stakeholders (if needed)
